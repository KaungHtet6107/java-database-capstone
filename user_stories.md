# User Stories - Patient Appointment Portal

## Admin User Stories

### User Story 1
**As an Admin, I want to log in securely so that I can manage the system.**

### User Story 2
**As an Admin, I want to add, update, and remove doctor accounts so that the doctor information remains accurate.**

### User Story 3
**As an Admin, I want to manage patient accounts so that I can maintain correct patient records.**

### User Story 4
**As an Admin, I want to view all appointments so that I can monitor the appointment schedule.**

### User Story 5
**As an Admin, I want to manage doctor specialties so that patients can find the appropriate doctor.**

---

## Patient User Stories

### User Story 1
**As a Patient, I want to create an account so that I can access the appointment system.**

### User Story 2
**As a Patient, I want to log in securely so that my personal information is protected.**

### User Story 3
**As a Patient, I want to search for doctors by specialty so that I can find the right doctor for my needs.**

### User Story 4
**As a Patient, I want to book an appointment so that I can receive medical care.**

### User Story 5
**As a Patient, I want to view my upcoming appointments so that I know my scheduled visits.**

### User Story 6
**As a Patient, I want to cancel or reschedule an appointment so that I can manage changes in my schedule.**

### User Story 7
**As a Patient, I want to view my appointment history so that I can keep track of my previous visits.**

---

## Doctor User Stories

### User Story 1
**As a Doctor, I want to log in securely so that I can access my dashboard.**

### User Story 2
**As a Doctor, I want to view my appointment schedule so that I can prepare for my patients.**

### User Story 3
**As a Doctor, I want to update my availability so that patients can book appointments during my available hours.**

### User Story 4
**As a Doctor, I want to view patient information before appointments so that I can provide better care.**

### User Story 5
**As a Doctor, I want to mark appointments as completed so that patient records remain up to date.**

### User Story 6
**As a Doctor, I want to write and update prescriptions so that patients receive the correct medication recommendations.**
